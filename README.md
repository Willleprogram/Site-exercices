# Site d'Exercices Scolaires 📚

Un site interactif pour réviser les mathématiques, français, anglais et autres matières scolaires avec des exercices par niveau (3e, 4e, 5e).

## 🎯 Fonctionnalités

- 📖 Exercices pour 8 matières différentes
- 📊 3 niveaux de classe (3e, 4e, 5e)
- 🎨 Interface moderne et responsive
- 💾 Stockage local des progrès
- 🔐 Système de connexion pour les utilisateurs

## 📂 Structure du Projet

```
Site exercices/
├── index.html              # Page d'accueil
├── style.css               # Feuille de styles
├── script.js               # Logique JavaScript
├── login.html              # Page de connexion
├── anglais 3e.html         # Exercices d'Anglais 3e
├── francais 3e.html        # Exercices de Français 3e
├── maths 3e.html           # Exercices de Maths 3e
└── ... (autres matières)
```

## 🚀 Comment utiliser localement

1. Cloner le repository:
```bash
git clone https://github.com/ton-utilisateur/site-exercices.git
```

2. Ouvrir `index.html` dans ton navigateur
